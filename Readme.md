# 🎮 Tic-Tac-Toe Game

## 📌 About the Project

This is a simple and interactive Tic-Tac-Toe game built using HTML, CSS, and JavaScript. Two players take turns marking the boxes with **O** and **X**. The game checks for winning combinations and displays a congratulatory message when a player wins.

This project helped me practice JavaScript DOM manipulation, event listeners, arrays, functions, and conditional statements.

## ✨ Features

- Two-player gameplay (O and X).
- Interactive 3 × 3 game board.
- Automatic winner detection.
- Eight winning patterns checked by JavaScript.
- Displays a winner message when a player wins.
- Disables selected boxes to prevent changing moves.
- Reset Game button to restart the game.
- New Game button to start a fresh game.

## 🛠️ Technologies Used

- **HTML5** — Structures the game board and buttons.
- **CSS3** — Styles the game interface.
- **JavaScript** — Handles player turns, game logic, winner detection, and resetting the game.

## 🚀 How to Run the Project

1. Download or clone the project repository.
2. Open the project folder.
3. Open the `index.html` file in your web browser.
4. Start playing Tic-Tac-Toe!

No additional installation is required for a basic HTML, CSS, and JavaScript version.

## 🎯 How to Play

1. The game starts with player O.
2. Players take turns selecting an empty box.
3. The selected box becomes O or X.
4. A player wins by placing three matching marks in a row, column, or diagonal.
5. After a winner is found, the remaining boxes are disabled.
6. Click **Reset** or **New Game** to play again.
